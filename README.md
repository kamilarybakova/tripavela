# Tripavela

Интерактивный Flutter-прототип для iOS и Android по `тз.md`. Все 28 экранов доступны в рабочих сценариях. Дополнительно предусмотрена браузерная демонстрация.

## Запуск

Требуется Flutter 3.44.6 / Dart 3.12.2 или совместимая версия. Первый запуск инструментов и загрузка пакетов требуют сети; установленное приложение использует локальные данные и изображения.

```sh
flutter pub get
flutter gen-l10n
flutter run
```

Выберите доступный симулятор или устройство в выводе `flutter devices`. Для браузера:

```sh
flutter run -d chrome
```

Сборки:

```sh
flutter build apk --debug
flutter build ios --simulator --no-codesign
flutter build web --no-web-resources-cdn
```

Android APK: `build/app/outputs/flutter-apk/app-debug.apk`.
iOS Simulator: `build/ios/iphonesimulator/Runner.app`.

Для запуска готовой web-сборки:

```sh
python3 -m http.server 8787 --bind 127.0.0.1 --directory build/web
```

Откройте http://127.0.0.1:8787. Браузерная версия хранит данные в IndexedDB; это отдельное хранилище от мобильного приложения. Временный localhost-сервер не публикует проект в интернете.

## Демонстрация

1. Пропустите или пройдите онбординг, выберите один из пяти городов.
2. Подберите прогулку: например, «Замедлиться», до четырёх часов, умеренный бюджет, пешком.
3. Выберите «Рынок, трамвай и море», проверьте условия и начните прогулку.
4. Подтверждайте прибытие кнопкой «Я на месте». Геопозиция не нужна.
5. Выполните необязательную миссию, добавьте заметку или фото.
6. Через «Место закрыто или не подходит» выберите причину и подготовленную замену.
7. После второй остановки выберите одну из двух веток.
8. Пройдите остальные места или пропустите их; завершите прогулку и откройте атлас.
9. Проверьте паузу и восстановление после перезапуска.

Профиль → Настройки → Панель демонстрационных сценариев: закрытое место, плохая погода, отсутствие замен, ошибка карт, ошибка сохранения, поздний старт. Пресеты «Новый пользователь», «Есть активная прогулка», «Прогулка на паузе», «Заполненный атлас» запрашивают подтверждение замены текущего локального набора.

Ошибку сохранения можно выключить в демопанели: управление демосценариями остаётся доступным при включённой симуляции ошибки.

## Устройство проекта

- `lib/core/theme.dart` — светлая и тёмная темы, палитра, типографика и стили компонентов.
- `lib/ui/components.dart` — карточки, панели, нижние действия и локальная схема.
- `lib/ui/screens.dart` — оболочка четырёх вкладок, онбординг, подбор, каталог и подготовка.
- `lib/ui/trip_screens.dart` — прохождение, миссии, замена, развилка, пауза и итоги.
- `lib/ui/atlas_screens.dart` — атлас, история, фото, заметки, профиль и настройки.
- `lib/domain/models.dart` — модели и детерминированный подбор.
- `lib/domain/repositories.dart` — контракты каталога, сессий, атласа, предпочтений и избранного.
- `lib/data/store.dart` — состояние Riverpod, локальная реализация репозиториев, транзакции и переходы сессии.
- `lib/data/database*.dart` — Sembast на мобильных платформах и IndexedDB в браузере; постоянное хранение фотографий.
- `lib/l10n/app_ru.arb` — тексты интерфейса и параметризованные сообщения. Код локализации генерируется стандартным `flutter gen-l10n`.
- `assets/data/catalog.json` — Стамбул: 15 активных маршрутов и 109 точек, включая архив для старых прогулок, развилки, замены, расходы, расписания и подготовленные переходы.

Виджеты не читают JSON и не изменяют файлы напрямую. Переходы прохождения сначала сохраняются транзакцией; ошибка оставляет предыдущий прогресс. Видимость остановки хранится отдельно от посещения. Запись посещения уникальна для шага сессии. Повторное посещение добавляется к тому же месту атласа.

Фотографии копируются в постоянную директорию приложения. В web-демо изображение хранится в локальной БД. Удаление истории сохраняет открытия и личные материалы; полный сброс удаляет весь локальный набор с подтверждением. Предусмотрено безопасное восстановление состояния с отдельной резервной записью повреждённых структурированных данных.

## Проверки

```sh
flutter test
flutter analyze
```

В установленном Flutter SDK обнаружен сбой LSP при запуске `flutter analyze` из каталога с кириллическим именем. `python3 tool/analyze.py` проверяет актуальные исходники в отдельной временной ASCII-копии без изменения оригинала. Это обход сбоя инструмента, а не отключение правил анализатора.

Тесты покрывают обязательные ограничения, неизвестную доступность, расписания, ветки и расчёты, идемпотентность прибытия, замену, пропуск, ошибки сохранения, восстановление паузы и повторное посещение. Есть полный сценарий через кнопки настоящего приложения и проверка отрисовки S01–S28 на нескольких размерах экрана и увеличенном шрифте.

Реестр экранов: `docs/screens.md`. Визуальные снимки: `docs/screenshots/`.

## Демонстрационные ограничения

Места и исторический контекст сверены по источникам 22.10.2026; ссылки есть у открытых остановок. Координаты и пешие переходы приблизительные, полевая проверка не проводилась. Часы конкретных заведений и цены не гарантируются: суммы еды — редакционный бюджет на необязательный перекус, а не меню. Большинство приключений рассчитаны на бесплатный наружный осмотр. Два маршрута SALT — четыре действия внутри одного культурного здания; учитываются понедельник и часы открытия. Фотографии показывают районы, не каждую остановку. Атрибуция и лицензии — assets/images/SOURCES.md. Для нового каталога используется отдельное локальное хранилище: старые сессии не подменяются новыми местами. Исходное ТЗ оставлено без изменений.

Нет backend, авторизации, оплаты, AI-генерации, автоматической геолокации и онлайн-проверки погоды. Карты открываются внешним приложением и могут требовать сеть; при ошибке доступно копирование адреса. Схема внутри приложения — иллюстрированная последовательность известных остановок.

События остаются локальными и не содержат заметок или фотографий. Синхронизация и облачное резервное копирование отсутствуют.

## Изображения и шрифты

Фотографии загружены с Unsplash и включены в локальные assets: city, coffee, art, food, park, street, books. Источники перечислены в `assets/images/SOURCES.md`.

Cormorant Garamond (прямое и курсивное начертания), Manrope и Golos Text распространяются по SIL Open Font License. Лицензии находятся в `assets/fonts/`. Шрифты встроены в приложение, сетевых запросов к Google Fonts нет.

## Визуальный стиль

Текущая версия использует редакционную концепцию по предоставленному референсу SOLIS: фон айвори, терракотовые акценты, спокойный серо-голубой дополнительный цвет, антиква Cormorant Garamond, настоящий курсив в крупных заголовках и плотные начертания Manrope в элементах управления. Карточки, поля и плавающая нижняя навигация оформлены общей системой. Подробности — `docs/design.md`.

Каталог Стамбула и источники: [docs/istanbul-content.md](docs/istanbul-content.md).

Подбор: точные совпадения соблюдают ограничения. Если совпадений нет, показываются близкие варианты с перечнем изменений. Условия сохраняются только после нажатия «Применить условия и посмотреть». Автоматическая проверка покрывает 2048 сочетаний параметров; ограничения доступности и помещений имеют приоритет при выборе предложений.

Карта и пешая навигация: [docs/navigation.md](docs/navigation.md). На активной прогулке доступна интерактивная карта с GPS, пешим путём, текущей целью и полноэкранным режимом. Для проверки вне Стамбула используйте «Посмотреть пример». Новый расчёт и уличная подложка требуют сети; полученный путь хранится локально.

Планирование поездок на 2–7 дней: на главной откройте «Поездка на несколько дней». Вайб, интересы, район отеля и время приезда определяют локальный демо-план. Подробности: [планировщик](docs/planning.md).

## Пять городов и поездки по дням

75 активных прогулок: Стамбул, Баку, Тбилиси, Дубай и Нячанг — по 15. Главный сценарий — план поездки на 2–7 дней с интересом «Шопинг». Подробности и ограничения: [docs/destinations.md](docs/destinations.md).

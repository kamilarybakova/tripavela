## Подбор без тупика

Сначала показываются точные совпадения. Если их нет — до трёх близких вариантов с минимальными изменениями. Предпочтение получают варианты, сохраняющие требования доступности, отдыха, помещений и питания. Каждое изменение отображается до выбора; новые условия сохраняются только после явного принятия. Переход на другую дату учитывает понедельник для SALT. Неподходящий вариант можно отменить без изменений.

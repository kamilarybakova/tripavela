# Tripavela artwork

`tripavela-icon-source.png` — оригинальная иконка, предоставленная пользователем: чёрная буква T с терракотовым крылом на белом фоне.

`tool/create_icons.py` экспортирует размеры для iOS, Android, PWA и favicon, а также изображение запуска iOS и `assets/images/app-icon.png` для интерфейса. Рисунок сохраняется; применяются только масштабирование, белая непрозрачная подложка и дополнительное безопасное поле у maskable-иконок.
